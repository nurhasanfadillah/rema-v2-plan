Verifikasi order lifecycle lengkap via MCP Playwright — dari buat pesanan (draft) hingga status shipped, plus skenario returned dan cancelled.

## Purpose
Order adalah fitur inti aplikasi. Memastikan seluruh status flow dan transisi berjalan benar di production.

## Output
Screenshot setiap transisi status; dokumentasi pass/fail di SUMMARY.md.
</objective>

<acceptance_criteria>

## AC-1: Buat Pesanan Baru (Draft)
```gherkin
Given admin login dan berada di /orders/create
When mengisi form pesanan lengkap (mitra, produk, kuantitas, catatan) dan submit
Then pesanan tersimpan dengan status draft, muncul di daftar /orders
```

## AC-2: Transisi Status — Draft ke Shipped
```gherkin
Given pesanan dengan status draft ada di sistem
When admin mengubah status secara berurutan: draft → waiting_confirmation → confirmed → processing → pressing → packing → shipped
Then setiap transisi tersimpan dan tampil di order detail, isBilled = true saat packing
```

## AC-3: Pesanan Cancelled
```gherkin
Given pesanan dalam status apapun sebelum shipped
When admin membatalkan pesanan
Then status berubah ke cancelled, muncul di /cancellations
```

## AC-4: Pesanan Returned
```gherkin
Given pesanan dengan status shipped
When admin memproses return
Then status berubah ke returned, muncul di /cancellations
```

## AC-5: Filter & Pencarian Order
```gherkin
Given halaman /orders dengan multiple pesanan
When admin memfilter/mencari berdasarkan nama mitra atau status
Then daftar order terfilter sesuai kriteria
```

## AC-6: Upload File di Order (Bukti Resi)
```gherkin
Given order detail page terbuka
When mengupload bukti resi
Then file tersimpan di R2, URL menggunakan storage.jisoi.net
```
