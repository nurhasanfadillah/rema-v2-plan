<acceptance_criteria>

## AC-1: Login Berhasil
```gherkin
Given halaman login https://redone.my.id/login terbuka
When admin mengisi nomor 082113133165 dan password yang benar
Then redirect ke dashboard (/), sidebar tampil, toast "Berhasil masuk" muncul
```

## AC-2: Login Gagal
```gherkin
Given halaman login terbuka
When admin mengisi nomor benar tapi password salah
Then tetap di halaman login, toast error tampil, tidak ada redirect
```

## AC-3: Navigasi Sidebar — Semua Halaman
```gherkin
Given admin sudah login
When mengklik setiap menu di sidebar (Dashboard, Users, Mitras, Products, Orders, Queue, Finance, Reports, AuditLogs, Cancellations)
Then URL berubah sesuai route, halaman ter-render tanpa error console, tidak ada blank screen
```

## AC-4: Akses Langsung URL (Deep Link)
```gherkin
Given admin sudah login
When mengakses URL https://redone.my.id/mitras langsung (refresh/direct access)
Then halaman Mitras ter-render, bukan 404
```

## AC-5: Logout
```gherkin
Given admin sudah login di dashboard
When mengklik tombol logout
Then redirect ke /login, token dihapus, akses ke / menampilkan login lagi
```
