## AC-1: Finance — Ledger Mitra
```gherkin
Given admin berada di /finance
When memilih salah satu mitra
Then ledger entries (debit/kredit) ditampilkan, saldo mitra dihitung benar
```

## AC-2: Finance — Catat Pembayaran
```gherkin
Given finance page mitra terbuka
When admin mencatat pembayaran (kredit) dari mitra
Then ledger entry baru muncul, saldo ter-update, ada input upload bukti bayar
```

## AC-3: AppQueue — Antrian Produksi
```gherkin
Given admin berada di /queue
When halaman ter-render
Then daftar order dalam antrian ditampilkan, status DTF (belum_cetak/sudah_cetak) untuk item dengan isCustomLogo tampil
```

## AC-4: Reports — Generate PDF
```gherkin
Given admin berada di /reports
When memilih rentang tanggal dan klik generate
Then report ter-render atau PDF download dipicu, tidak ada console error
```

## AC-5: AuditLogs — Riwayat Aktivitas
```gherkin
Given admin berada di /audit-logs
When halaman ter-render
Then daftar aktivitas admin tampil (minimal ada log dari sesi testing ini)
```

## AC-6: CancellationsReturns — Daftar Lengkap
```gherkin
Given pesanan cancelled dan returned sudah ada (dari Plan 09-03)
When admin berada di /cancellations
Then daftar cancelled dan returned tampil, bisa dibedakan per status
```

## AC-7: Credit Limit Warning
```gherkin
Given mitra memiliki credit limit tertentu
When total hutang mitra mendekati atau melebihi credit limit
Then ada indikator visual peringatan di halaman finance atau mitra
```
