## AC-1: Tambah Mitra Baru
```gherkin
Given admin login dan berada di halaman /mitras
When mengisi form tambah mitra (nama, nomor, credit limit) dan submit
Then mitra baru muncul di daftar, data tersimpan di DB (reload halaman masih ada)
```

## AC-2: Edit Mitra
```gherkin
Given mitra sudah ada di daftar
When mengklik edit pada mitra tersebut, mengubah nama, dan menyimpan
Then nama mitra terupdate di daftar, perubahan persisten setelah reload
```

## AC-3: Upload Logo Mitra
```gherkin
Given form edit mitra terbuka
When mengupload file gambar sebagai logo
Then logo tersimpan di R2, URL gambar menggunakan storage.jisoi.net, dan preview logo tampil
```

## AC-4: Tambah Produk Baru
```gherkin
Given admin berada di halaman /products
When mengisi form tambah produk (nama, harga, dll) dan submit
Then produk baru muncul di daftar
```

## AC-5: Edit Produk + Upload Foto
```gherkin
Given produk sudah ada
When mengklik edit, mengubah nama/harga, mengupload foto produk, dan menyimpan
Then data terupdate, foto disimpan di R2
```

## AC-6: Validasi Form (Field Required)
```gherkin
Given form tambah mitra/produk terbuka
When submit tanpa mengisi field wajib
Then form menampilkan validasi error, tidak ada data tersimpan di DB
```

## AC-7: Manajemen User
```gherkin
Given admin berada di /users
When melihat daftar user
Then daftar user ter-render, data tampil benar
```
