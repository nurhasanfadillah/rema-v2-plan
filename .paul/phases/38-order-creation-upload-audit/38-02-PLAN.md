<objective>
## Goal
Naikkan batas ukuran file upload dari 10MB ke 50MB di semua 3 tempat (frontend + backend), dan tambah konfigurasi memory Vercel agar function cukup RAM untuk buffer file besar.

## Purpose
File desain garmen (CDR, AI, PDF hi-res, foto produk) sering melebihi 10MB. Batasan ini menyebabkan upload gagal tanpa pesan error yang jelas. Perubahan ini membuka kapasitas upload ke 50MB, cukup untuk kebutuhan produksi saat ini.

## Output
- `src/components/FileUpload.tsx` — limit 50MB
- `src/components/MultiFileUpload.tsx` — limit 50MB
- `src/api/routes/upload.ts` — express.raw limit 50mb
- `vercel.json` — memory 1024MB untuk function
</objective>
