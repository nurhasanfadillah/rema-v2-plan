<objective>
## Goal
Panel "Detail Info Mitra" (admin) mendapat tombol **Cetak PDF** di bagian Tindakan yang mengunduh PDF satu halaman untuk mitra yang sedang dibuka. Isinya sama dengan panel: nama, status, akun penanggung jawab + kontak, limit kredit, Total Penjualan, Jumlah Pesanan, Saldo Piutang.

## Purpose
Admin bisa mencetak atau membagikan profil dan posisi satu mitra tanpa menyalin dari layar (permintaan user 2026-10-23, lanjutan Plan 46-01). Angka PDF identik dengan panel karena memakai `stats` yang sama, tanpa perhitungan baru.

## Output
- Modul `mitra-export` bertambah: tipe + `buildMitraDetail` + `buildMitraDetailFileName` (murni), `MitraDetailPDF` + `createMitraDetailPdfBlob`, `exportMitraDetailPdf` (lewat `import()` dinamis), dan `exportMitraDetail` di hook `useMitraPdfExport`
- `Mitras.tsx`: tombol Cetak PDF di Tindakan panel; props `onExportPdf` dan `isExporting` untuk `MitraDetailPanel`
</objective>

## Keputusan Perencanaan
- **Isi PDF = sama dengan panel** (pilihan user 2026-10-23): 1 halaman, tanpa daftar transaksi, tanpa logo. Judul "Detail Info Mitra" (sama dengan judul panel); status "Partner Aktif" / "Terarsip" (sama dengan panel); label "Jumlah Pesanan" (konsisten dengan Daftar Mitra, bukan "Volume Pesanan"/"items" di panel).
- **Satu sumber angka:** `stats` dari `getMitraStats` yang sama dengan yang ditampilkan panel diteruskan ke `buildMitraDetail`, yang hanya memetakan (tanpa menghitung ulang). Limit yang dicetak adalah nilai tersimpan (`mitra.creditLimit`), bukan isi kolom editor yang belum disimpan.
- **Penanggung jawab dan kontak:** dari `mitraUser` (akun), "-" bila tidak ada, seperti panel.
- **Tombol:** di bagian Tindakan, baris penuh (`col-span-2`) tepat di atas "Hapus Mitra", gaya biru lembut (`bg-blue-500/10 text-blue-400 border-blue-500/20`) dengan ikon `Download`; hanya tampil di mode lihat (bagian Tindakan memang tidak ada di mode edit); tidak menutup panel.
- **Satu `isExporting`:** hook yang sama dengan tombol header; selama satu ekspor jalan, kedua tombol nonaktif dan ekspor kedua ditolak penjaga `useRef`.
- **Nama berkas:** `Mitra_<NAMA_AMAN>_<yyyy-MM-dd>.pdf`; nama aman = tanpa diakritik, selain huruf/angka ASCII diganti `_`, maksimal 40 karakter, kosong atau tak terbaca -> `Tanpa_Nama`.
- **Pola 46-01 dipakai ulang:** `import()` dinamis hanya ke berkas PDF, pembuat blob di berkas PDF, `toPdfSafeText` untuk teks dinamis, `downloadBlob`, jalur eager bebas `date-fns`, barrel tidak mengekspor komponen PDF.
- **Konvensi:** folder + `index.ts`, kebab-case, named export, tanpa `any` di kode baru, `import type` di fungsi murni, logika di fungsi/hook bukan di komponen.

<acceptance_criteria>

## AC-1: Tombol Cetak PDF di panel mengunduh PDF mitra
```gherkin
Given admin membuka panel "Detail Info Mitra" (mode lihat) untuk satu mitra
When admin mengklik "Cetak PDF" di bagian Tindakan
Then berkas Mitra_<NAMA_AMAN>_<yyyy-MM-dd>.pdf terunduh dan panel tetap terbuka
And PDF satu halaman memuat judul "Detail Info Mitra", cap "Dicetak: ...", nama mitra (huruf besar), status, kotak Total Penjualan / Jumlah Pesanan / Saldo Piutang, Akun Penanggung Jawab, Kontak WhatsApp, Limit Kredit, dan catatan kaki definisi
```

## AC-2: Angka identik dengan panel
```gherkin
Given panel menampilkan stats mitra dari getMitraStats
When PDF dan panel dibandingkan
Then Total Penjualan, Jumlah Pesanan, Saldo Piutang, nama, status, penanggung jawab, kontak, dan limit kredit identik
And PDF memakai stats yang sama dengan panel (tanpa perhitungan ulang)
```

## AC-3: Fallback dan format
```gherkin
Given mitra tanpa akun penanggung jawab, mitra tanpa limit (null atau 0), mitra arsip, dan mitra dengan Saldo Piutang negatif
When PDF masing-masing dibuat
Then penanggung jawab dan kontak tampil "-"; limit tampil "Unlimited"; status tampil "Terarsip"
And Saldo Piutang > 0 berwarna merah, <= 0 hijau, dan nilai negatif tampil "-Rp ..."
```

## AC-4: Nama berkas aman dan teks dinamis aman
```gherkin
Given nama mitra berisi spasi, tanda baca, aksen, emoji, CJK, atau lebih dari 40 karakter
When PDF diunduh
Then nama berkas hanya huruf/angka ASCII dan "_" (diakritik dibuang, maksimal 40 karakter pada bagian nama, kosong -> Tanpa_Nama)
And isi PDF tidak memuat karakter rusak (emoji/CJK dibuang, aksen Latin-1 tetap) dan pembuatan PDF tidak gagal
```

## AC-5: Status ekspor bersama dan galat
```gherkin
Given admin mengklik "Cetak PDF" di panel
When PDF sedang dibuat
Then tombol di panel berlabel "Membuat PDF..." dan nonaktif, tombol Cetak PDF di header halaman juga nonaktif
And ekspor kedua tidak berjalan paralel
And bila pembuatan gagal, toast error "Gagal membuat PDF" tampil, tombol aktif kembali, dan panel tetap terbuka
```

## AC-6: Library PDF tetap lazy
```gherkin
Given build produksi
When graf import statis dari entry diperiksa
Then Mitras.tsx dan index.ts modul tidak meng-import @react-pdf/renderer maupun mitra-detail-pdf secara statis
And mitra-detail-pdf menjadi chunk terpisah yang diminta lewat import() saat tombol diklik
And ukuran chunk entry bertambah kurang dari 3 kB dibanding baseline Plan 46-01 (559.588 B) dan chunk vendor-pdf tidak berubah (1.466.869 B)
```

## AC-7: Panel dan halaman tidak berubah selain tombol baru
```gherkin
Given halaman Manajemen Mitra dan panel Detail Info Mitra
When dibuka setelah perubahan ini
Then Edit Profil, Batasi/Buka Akses, Hapus Mitra, editor Limit Kredit, dan mode edit berfungsi seperti sebelumnya
And tombol Cetak PDF tidak tampil di mode edit
And tombol Cetak PDF di header (Daftar Mitra), tabel/kartu, dan angka di layar tidak berubah
```
