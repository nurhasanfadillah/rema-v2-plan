<objective>
## Goal
Halaman Manajemen Mitra (`/mitras`, admin) mendapat tombol **Cetak PDF** di header yang mengunduh "Laporan Daftar Mitra": semua mitra (aktif + arsip) dengan Total Penjualan, Jumlah Pesanan, Saldo Piutang, Limit Kredit, dan Status, plus baris TOTAL. Angkanya identik dengan layar karena satu fungsi hitung dipakai bersama.

## Purpose
Admin bisa mencetak/membagikan posisi seluruh mitra (penjualan, piutang, limit) tanpa menyalin dari layar (permintaan user 2026-10-23). Plan ini juga menyiapkan fondasi modul `mitra-export` yang dipakai ulang oleh Plan 46-02 (PDF per mitra dari panel Detail Info Mitra).

## Output
- Modul baru `src/components/mitras/mitra-export/` (9 file, public API `index.ts`): tipe, fungsi murni hitung/ringkasan, sanitasi teks PDF, PDF Daftar Mitra, ekspor lewat `import()` dinamis, hook `useMitraPdfExport`
- `Mitras.tsx`: tombol Cetak PDF di header; `getMitraStats` memanggil fungsi murni modul (perilaku layar tidak berubah)
</objective>

<acceptance_criteria>

## AC-1: Tombol Cetak PDF mengunduh Daftar Mitra
```gherkin
Given admin membuka /mitras dan minimal 1 mitra termuat
When admin mengklik "Cetak PDF" di header halaman
Then berkas Daftar_Mitra_YYYY-MM-DD.pdf (tanggal hari ini) terunduh
And PDF memuat semua mitra (aktif dan arsip) dengan kolom No, Mitra (nama + "HP: ..."), Total Penjualan, Jumlah Pesanan, Saldo Piutang, Limit Kredit ("Unlimited" bila tanpa limit), Status (Aktif/Arsip)
And PDF memuat judul, cap "Dicetak: ...", ringkasan (Total Mitra, Total Penjualan, Total Pesanan, Total Saldo Piutang), baris TOTAL, dan catatan kaki definisi
```

## AC-2: Angka identik dengan layar
```gherkin
Given data mitra, pesanan, dan ledger yang sama
When angka per mitra di PDF dibandingkan dengan tabel desktop / kartu mobile di layar
Then Total Penjualan, Jumlah Pesanan, dan Saldo Piutang identik (keduanya dihitung calculateMitraStats)
And ringkasan dan baris TOTAL sama dengan jumlah seluruh baris
And tampilan layar tidak berubah selain tombol baru di header
```

## AC-3: Urutan dan format baris
```gherkin
Given mitra dengan nama dalam urutan acak dan sebagian tanpa akun penanggung jawab
When PDF dibuat
Then baris terurut nama A-Z (tidak peka huruf besar/kecil, locale id)
And mitra tanpa akun menampilkan "HP: -"
And Saldo Piutang > 0 berwarna merah, <= 0 berwarna hijau, dan nilai negatif tampil "-Rp ..."
```

## AC-4: Multi-halaman
```gherkin
Given daftar mitra lebih dari satu halaman (mis. 49 mitra)
When PDF dibuat
Then header tabel berulang di setiap halaman dan tidak ada baris terbelah di batas halaman
And footer menampilkan "Halaman X / Y" yang benar
And baris TOTAL muncul di akhir tabel
```

## AC-5: Nama dengan karakter tak didukung
```gherkin
Given nama mitra berisi emoji, huruf CJK, atau karakter Latin-1 (aksen, em dash, tanda kali)
When PDF dibuat
Then emoji/CJK tidak tercetak sebagai karakter rusak (dibuang; nama yang menjadi kosong tampil "-")
And aksen, em dash, dan tanda kali Latin-1 tetap tampil benar
And proses pembuatan PDF tidak gagal
```

## AC-6: Library PDF dimuat saat diklik
```gherkin
Given build produksi
When graf import statis dari entry diperiksa
Then Mitras.tsx dan index.ts modul tidak meng-import @react-pdf/renderer maupun mitra-list-pdf secara statis
And mitra-list-pdf menjadi chunk terpisah yang diminta lewat import() saat tombol diklik
And ukuran chunk entry bertambah kurang dari 8 kB dibanding baseline 557,79 kB (HEAD 2276e42)
```

## AC-7: Status ekspor dan penanganan galat
```gherkin
Given admin mengklik "Cetak PDF"
When PDF sedang dibuat
Then tombol nonaktif dan berlabel "Membuat PDF..." sampai selesai
And bila pembuatan gagal, toast error "Gagal membuat PDF" tampil dan tombol aktif kembali
And tombol nonaktif bila belum ada mitra
```
