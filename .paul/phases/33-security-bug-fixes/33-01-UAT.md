### UAT-001 — Missing `and` import in ledgers.ts
**Severity:** Blocker  
**File:** `src/api/routes/ledgers.ts`  
**Description:**  
Fungsi `and()` dari drizzle-orm digunakan di baris 38–44 untuk cek duplikasi ledger pada `POST /api/ledgers`, tetapi tidak ada di import (baris 2 hanya import `eq, desc`). Ini menyebabkan `ReferenceError: and is not defined` setiap kali `POST /api/ledgers` dipanggil dengan `source='order'`, yaitu saat pesanan masuk status `packing`.

**Steps to reproduce:**  
1. Ubah status pesanan ke `packing`
2. Frontend memanggil `POST /api/ledgers` dengan `{ source: 'order', referenceId: orderId }`
3. API crash dengan ReferenceError

**Expected:** Ledger debit berhasil dibuat  
**Actual:** Server 500 — `ReferenceError: and is not defined`

**AC Reference:** Billing harus dibuat saat pesanan masuk packing

### UAT-002 — Backend orders API tidak ada role check untuk PUT/DELETE/POST
**Severity:** Blocker  
**File:** `src/api/routes/orders.ts`  
**Description:**  
Endpoint `PUT /api/orders/:id`, `DELETE /api/orders/:id`, dan `POST /api/orders` hanya menggunakan `requireAuth` tanpa validasi role atau ownership. Akibatnya:
- Role `operational` atau `mitra` bisa update/delete order milik mitra lain
- Role `staff`/`operational` bisa membuat order (seharusnya hanya `mitra`)
- `PUT /api/orders/:id` menerima perubahan `status`, `isBilled`, `totalAmount` tanpa validasi apapun

**AC Reference:** Hanya mitra yang bisa buat pesanan; admin/staff yang bisa update status; ownership harus diverifikasi

### UAT-003 — `allMitras=true` bypass filter tersedia untuk semua role
**Severity:** Major  
**File:** `src/api/routes/orders.ts` baris 12–13  
**Description:**  
Query param `?allMitras=true` pada `GET /api/orders` dapat digunakan oleh siapapun termasuk `mitra` untuk melihat semua orders dari semua mitra. Tidak ada pengecekan bahwa hanya `admin`/`staff` yang boleh menggunakan parameter ini.

**Steps to reproduce:**  
1. Login sebagai mitra
2. Request `GET /api/orders?allMitras=true`
3. Semua orders semua mitra dikembalikan

**Expected:** 403 Forbidden untuk mitra  
**Actual:** Semua orders dikembalikan

### UAT-006 — Dua jalur pembatalan/retur tidak terhubung — Intent Issue
**Severity:** Minor → **reclassified Major after UAT**  
**Files:** `src/pages/orders/OrderDetail.tsx`, `src/pages/CancellationsReturns.tsx`

### UAT-008 — AppQueue mitra hanya melihat pesanannya sendiri (regresi Phase 33)
**Severity:** Major  
**File:** `src/api/routes/orders.ts`, `src/pages/AppQueue.tsx`  
**Description:**  
Phase 33 fix membatasi `allMitras=true` bypass ke admin/staff saja. Namun `AppQueue.tsx` memanggil `api.orders.list(true)` untuk semua role — termasuk mitra. Akibatnya, mitra yang membuka Antrian Produksi hanya melihat pesanannya sendiri, bukan seluruh antrian produksi.

**Expected:** Semua role (termasuk mitra) dapat melihat seluruh antrian produksi yang sedang berjalan  
**Actual:** Mitra hanya melihat pesanannya sendiri di AppQueue

**Fix:**  
- Tambah `queueView=true` parameter di backend yang bypass mitra filter untuk semua role (shared production view)  
- Tambah `api.orders.listQueue()` di `api.ts`  
- `AppQueue.tsx` gunakan `listQueue()` bukan `list(true)`

**Status:** ✅ Fixed — 2026-06-05
