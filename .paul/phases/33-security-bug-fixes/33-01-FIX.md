**1. GET / — Amankan `allMitras` bypass (UAT-003):**
Ubah kondisi bypass menjadi:
```ts
const bypassMitra = req.query.allMitras === 'true' && 
  (req.user.role === 'admin' || req.user.role === 'staff');
```
Artinya: mitra yang kirim `?allMitras=true` tetap di-filter ke mitraId miliknya.

**2. GET /:id — Tambah ownership check (UAT-004):**
Setelah fetch order, jika role adalah `mitra`:
- Fetch mitra record berdasarkan `req.user.sub` (userId)
- Jika `order.mitraId !== mitra.id` → return 403

**3. POST / — Tambah role check (UAT-002):**
Di awal handler, tambahkan:
```ts
if (req.user.role !== 'mitra') {
  return res.status(403).json({ error: 'Hanya mitra yang dapat membuat pesanan' });
}
```

**4. PUT /:id — Tambah ownership check untuk mitra (UAT-002):**
Setelah fetch existing order, jika role adalah `mitra`:
- Fetch mitra record berdasarkan `req.user.sub`
- Jika `existingOrder.mitraId !== mitra.id` → return 403

**5. DELETE /:id — Tambah ownership check untuk mitra (UAT-002):**
Fetch order dulu, jika role adalah `mitra`:
- Fetch mitra record berdasarkan `req.user.sub`
- Jika `order.mitraId !== mitra.id` → return 403

Catatan penting:
- Gunakan `AuthRequest` type (sudah diimport) untuk akses `req.user`
- Lookup mitra dengan `db.select().from(mitras).where(eq(mitras.userId, req.user.sub)).limit(1)`
- Admin dan staff boleh akses semua orders tanpa batasan ownership

<task type="auto">
  <name>Fix UAT-005: Role check di requests.ts</name>
  <files>src/api/routes/requests.ts</files>

Saat ini `requests.ts` menggunakan `Request` bukan `AuthRequest`. Ubah ke `AuthRequest` agar bisa akses `req.user`.

**Perubahan imports:**
```ts
import { requireAuth, type AuthRequest } from '../middleware/auth.ts';
import { eq, desc } from 'drizzle-orm';
import { db } from '../../db/client.ts';
import { actionRequests, mitras } from '../../db/schema.ts';
```

**1. GET / — Filter by mitraId untuk role mitra (UAT-005):**
```ts
router.get('/', async (req: AuthRequest, res: Response) => {
  let result;
  if (req.user.role === 'mitra') {
    const [mitra] = await db.select().from(mitras)
      .where(eq(mitras.userId, req.user.sub)).limit(1);
    if (!mitra) return res.status(403).json({ error: 'Mitra not found' });
    result = await db.select().from(actionRequests)
      .where(eq(actionRequests.mitraId, mitra.id))
      .orderBy(desc(actionRequests.createdAt));
  } else {
    result = await db.select().from(actionRequests)
      .orderBy(desc(actionRequests.createdAt));
  }
  return res.json(result);
});
```

```ts
if (req.user.role !== 'admin' && req.user.role !== 'staff') {

}
```

**3. POST / — Pertahankan seperti sekarang** (mitra membuat request, ini benar)
