## AC-1: Filter status disesuaikan
```gherkin
Given halaman `/app-queue` mengambil daftar pesanan via `api.orders.listQueue()`
When halaman merender daftar antrian
Then hanya pesanan berstatus `waiting_confirmation`, `confirmed`, `processing`, atau `pressing` yang tampil (di semua tampilan: pipeline cards, mobile list, desktop table)

```

## AC-2: 4 pipeline cards menampilkan status baru dengan urutan alur
```gherkin
Given halaman `/app-queue` dirender pada viewport desktop (≥ lg)
When user melihat grid pipeline stats cards
Then card #1 berlabel "MENUNGGU" (waiting_confirmation, warna amber, icon Hourglass)
And card #2 berlabel "DIKONFIRMASI" (confirmed, warna biru, icon CheckSquare)
And card #3 berlabel "DIPROSES" (processing, warna ungu, icon Clock)
And card #4 berlabel "SABLON" (pressing, warna rose/pink, icon Layers)
And setiap card menampilkan count (jumlah pesanan) + qty (total pcs) untuk status masing-masing
```

## AC-3: Badge, mobile left-border, desktop table row disesuaikan
```gherkin
Given pesanan berstatus `waiting_confirmation` muncul dalam daftar
When mobile card atau desktop table row dirender
Then badge status menampilkan label "Menunggu" dengan palette amber
And mobile card punya `border-l-amber-400`
And desktop table row punya `border-l-amber-400`
And badge label untuk `pressing` menjadi "Sablon" (bukan lagi "Press Sablon")
And entry `packing` di specs badge, statusLeftBorder, dan statusColor sudah dihapus (dead code)
```
