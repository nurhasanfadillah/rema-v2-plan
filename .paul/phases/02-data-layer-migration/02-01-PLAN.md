## AC-1: Endpoint Mitras Berfungsi

```gherkin
Given server berjalan dan token valid
When GET /api/mitras
Then return array semua mitra (termasuk yang isArchived)

When POST /api/mitras dengan body {id, userId, name, creditLimit, isArchived}
Then return mitra baru yang tersimpan di DB

When PUT /api/mitras/:id dengan partial body
Then return mitra yang sudah diupdate

When DELETE /api/mitras/:id
Then set isArchived=true (soft delete), return mitra terupdate
```

## AC-2: Endpoint Products Berfungsi

```gherkin
Given server berjalan dan token valid
When GET /api/products
Then return array semua produk

When POST /api/products
Then return produk baru tersimpan

When PUT /api/products/:id
Then return produk terupdate
```

## AC-3: Endpoint Users Berfungsi

```gherkin
Given server berjalan dan token valid
When GET /api/users
Then return array users (tanpa passwordHash)

When POST /api/users dengan {name, phone, password, role}
Then hash password dengan bcrypt, simpan user baru

When PUT /api/users/:id dengan body (bisa termasuk newPassword)
Then update user; jika ada newPassword → bcrypt hash dulu
```

## AC-4: Endpoint Orders Berfungsi (dengan Items)

```gherkin
Given server berjalan dan token valid
When GET /api/orders (optional: ?mitraId=X)
Then return array order lengkap dengan field items: OrderItem[]

When POST /api/orders dengan body {order fields, items: []}
Then insert ke tabel orders + orderItems dalam satu transaksi

When PUT /api/orders/:id dengan body (termasuk items)
Then update order row + replace semua orderItems (delete lama, insert baru)
```

## AC-5: Endpoint Ledgers, Requests, AuditLogs Berfungsi

```gherkin
Given server berjalan dan token valid

When GET /api/ledgers?mitraId=X
Then return ledger entries untuk mitra tersebut, diurutkan desc createdAt

When POST /api/ledgers
Then insert entry baru

When GET /api/requests
Then return semua action requests

When POST /api/requests
Then insert request baru

When PUT /api/requests/:id
Then update status dan field lainnya

When GET /api/audit-logs?limit=N
Then return N log terbaru (default 100)

When POST /api/audit-logs
Then insert audit log baru
```

## AC-6: Semua Route Diproteksi Auth

```gherkin
Given request tanpa Authorization header
When mengakses endpoint manapun (selain /api/health dan /api/auth/*)
Then return 401 Unauthorized
```

  <files>src/api/routes/orders.ts, src/api/routes/ledgers.ts, src/api/routes/requests.ts, src/api/routes/audit-logs.ts</files>
  <action>
    **src/api/routes/orders.ts** — paling kompleks karena relasi orders ↔ orderItems:

    `GET /` — dengan optional `?mitraId=X`:
    ```typescript
    // Fetch orders
    const allOrders = mitraId
      ? await db.select().from(orders).where(eq(orders.mitraId, mitraId))
      : await db.select().from(orders);

    // Fetch items for those orders
    const orderIds = allOrders.map(o => o.id);
    const allItems = orderIds.length > 0
      ? await db.select().from(orderItems).where(inArray(orderItems.orderId, orderIds))
      : [];

    // Merge
    const result = allOrders.map(o => ({
      ...o,
      items: allItems.filter(i => i.orderId === o.id),
    }));
    return res.json(result);
    ```

    Import: `import { inArray, eq } from 'drizzle-orm'`

    `POST /` — body berisi order fields + `items: OrderItem[]`:
    ```typescript
    const { items, ...orderData } = req.body;
    // Gunakan db transaction
    await db.transaction(async (tx) => {
      await tx.insert(orders).values(orderData);
      if (items?.length) {
        await tx.insert(orderItems).values(
          items.map((item: any) => ({ ...item, orderId: orderData.id }))
        );
      }
    });
    ```

    `PUT /:id` — body berisi order fields + `items: OrderItem[]`:
    ```typescript
    const { items, ...orderData } = req.body;
    await db.transaction(async (tx) => {
      await tx.update(orders).set(orderData).where(eq(orders.id, req.params.id));
      // Replace items: delete lama, insert baru
      await tx.delete(orderItems).where(eq(orderItems.orderId, req.params.id));
      if (items?.length) {
        await tx.insert(orderItems).values(
          items.map((item: any) => ({ ...item, orderId: req.params.id }))
        );
      }
    });
    ```
