<task type="auto">
  <name>Task 2: Tambah DELETE endpoint dan migrate Products.tsx</name>
  <files>src/api/routes/products.ts, src/lib/api.ts, src/pages/Products.tsx</files>
  <action>
    **Step A — src/api/routes/products.ts: tambah DELETE /:id**
    
    Tambah endpoint baru di bawah router.put():
    ```
    router.delete('/:id', async (req: Request, res: Response) => {
      try {
        // Cek apakah product dipakai dalam order_items
        const usedInOrders = await db
          .select()
          .from(orderItems)
          .where(eq(orderItems.productId, req.params.id))
          .limit(1);
        if (usedInOrders.length > 0) {
          return res.status(409).json({ error: 'Produk sudah digunakan dalam pesanan. Silakan arsipkan saja.' });
        }
        await db.delete(products).where(eq(products.id, req.params.id));
        return res.json({ ok: true });
      } catch (err: any) {
        return res.status(500).json({ error: err.message });
      }
    });
    ```
    Import orderItems dari schema: `import { products, orderItems } from '../../db/schema.ts'`
    Juga import `delete as drizzleDelete` jika perlu, atau gunakan `db.delete(products)`.
    
    **Step B — src/lib/api.ts: tambah api.products.remove()**
    
    Di objek `products` dalam api, tambah:
    ```
    remove: (id: string) => request<void>('DELETE', `/products/${id}`),
    ```
    
    **Step C — src/pages/Products.tsx: migrate ke api.***
    
    1. Hapus import db dari '../lib/db'
    2. Tambah import: `import { api } from '../lib/api'` dan `import { useEffect } from 'react'`
    3. Ubah useState initialization:
       - `useState<Product[]>(db.getProducts())` → `useState<Product[]>([])`
    4. Tambah useEffect setelah useState hooks (Products tidak punya early return di awal, jadi aman):
       ```

         api.products.list().then(setProducts).catch(console.error);
       }, []);
       ```
    5. Update handleArchive: ganti `db.saveProducts(newProducts)` dan `db.addAuditLog(...)` dengan:
       - `await api.products.update(id, { isArchived: !currentArchive })`
       - `await api.auditLogs.create({ userId: user.id, action: ..., details: ... })`
       - Setelah success, update state lokal via setProducts
       - Ubah signature menjadi `async`
    6. Update handleDelete: hapus `const orders = db.getOrders()` dan `isUsedInOrders` check (validasi sekarang server-side).
       - Ganti db calls dengan: `await api.products.remove(id)`
       - Jika API error 409, tampilkan toast.error dari err.message
       - `await api.auditLogs.create({ ... action: 'PRODUCT_DELETED' ... })`
       - Setelah success, update state lokal via setProducts(prev => prev.filter(p => p.id !== id))
    7. Update handleSave: ganti `db.saveProducts(newProducts)` dengan:
       - Jika idx !== -1 (update): `const updated = await api.products.update(prod.id, prod)` lalu update state
       - Jika baru (create): `const created = await api.products.create(prod)` lalu prepend ke state
       - `await api.auditLogs.create({ ... })`
       - Wrap dalam try/catch, toast.error jika gagal
       - Ubah handleSave menjadi async
