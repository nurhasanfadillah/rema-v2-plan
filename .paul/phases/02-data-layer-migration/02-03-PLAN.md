<objective>
## Goal
Migrasikan 4 halaman read-only (Dashboard, Reports, RunningOrders, AuditLogs) dari synchronous `db.*` calls ke async `api.*` calls.

## Purpose
Semua halaman ini hanya membaca data — tidak ada mutasi. Polanya seragam: ganti `const x = db.getX()` di component body menjadi `useState([])` + `useEffect(() => { api.x.list().then(setX) }, [])`. Setelah plan ini, 4 halaman bebas dari `db.*`.

## Output
- 4 file diupdate: db.* dihapus, diganti api.* dengan async loading
- Masing-masing file punya loading state saat fetch berlangsung
</objective>

  <action>
    **Pola yang sama untuk ketiga file:**

    Ketiga file saat ini memiliki synchronous reads di component body:
    ```
    const orders = db.getOrders();   // synchronous, langsung dari localStorage
    const mitras = db.getMitras();
    // dst
    ```

    Ubah ke async pattern:
    1. Hapus import `db` dari `'../lib/db'`
    2. Import `api` dari `'../lib/api'` (atau `'../../lib/api'` untuk komponen)
    3. Tambah `useEffect` ke import React jika belum ada
    4. Ubah setiap `const x = db.getX()` di component body menjadi:
       - `const [x, setX] = useState<Type[]>([])`
       - Plus `useEffect(() => { api.x.list().then(setX).catch(console.error) }, [])`
    5. Pindahkan semua useState dan useEffect SEBELUM any early returns (React hooks rule)

    **Dashboard.tsx spesifik:**
    - Line 12: `if (!user) return null` — ini harus dipindah ke SETELAH semua hooks
    - Tambah 3 state: `orders`, `ledgers`, `mitras` — masing-masing default `[]`
    - Fetch: `api.orders.list()`, `api.ledgers.list()`, `api.mitras.list()`
    - Early return `if (!user) return null` tetap ada tapi harus di bawah hook declarations
    - Semua computed values (myOrders, activeOrders, dll) sudah pakai useMemo atau inline computation — pertahankan logika, hanya ganti source data

    **Reports.tsx spesifik:**
    - Tambah 4 state: `mitras`, `products`, `allLedgers`, `allOrders`
    - Fetch: `api.mitras.list()`, `api.products.list()`, `api.ledgers.list()`, `api.orders.list()`

    - Tambah 2 state: `orders`, `mitras`
    - Fetch: `api.orders.list()`, `api.mitras.list()`
    - File hanya 58 baris — perubahan minimal

    **Jangan ubah JSX/UI sama sekali** — hanya ganti data source.
