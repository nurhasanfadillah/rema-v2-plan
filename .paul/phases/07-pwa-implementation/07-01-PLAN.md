Tambahkan PWA installability ke aplikasi REMA-V2 yang sudah live di https://redone.my.id, sehingga app bisa di-install ke home screen HP dan desktop.

Meningkatkan user experience admin agar app terasa seperti aplikasi native — full screen tanpa browser UI, load lebih cepat dengan shell caching.

- Icons PWA (192×192, 512×512, maskable) di `public/`
- `vite.config.ts` dikonfigurasi dengan `vite-plugin-pwa`
- Service worker + manifest auto-generated saat build
- App memenuhi PWA installability criteria di Chrome/Edge
</objective>

<task type="auto">
  <name>Task 2: Konfigurasi vite-plugin-pwa di vite.config.ts</name>
  <files>vite.config.ts</files>
  <action>
    Import dan tambahkan `VitePWA` plugin ke `vite.config.ts`:

    ```ts
    import { VitePWA } from 'vite-plugin-pwa'
    ```

    Tambahkan ke array `plugins` setelah `tailwindcss()`:

    ```ts
    VitePWA({
      registerType: 'autoUpdate',
      includeAssets: ['favicon.ico', 'pwa-*.png'],
      manifest: {
        name: 'REMA-V2',
        short_name: 'REMA-V2',
        description: 'Sistem manajemen pesanan dan keuangan mitra',
        theme_color: '#020617',
        background_color: '#020617',
        display: 'standalone',
        start_url: '/',
        scope: '/',
        icons: [
          {
            src: 'pwa-192x192.png',
            sizes: '192x192',
            type: 'image/png',
          },
          {
            src: 'pwa-512x512.png',
            sizes: '512x512',
            type: 'image/png',
          },
          {
            src: 'pwa-maskable-192x192.png',
            sizes: '192x192',
            type: 'image/png',
            purpose: 'maskable',
          },
          {
            src: 'pwa-maskable-512x512.png',
            sizes: '512x512',
            type: 'image/png',
            purpose: 'maskable',
          },
        ],
      },
      workbox: {
        globPatterns: ['**/*.{js,css,html,ico,png,svg,woff2}'],
        runtimeCaching: [],
      },
    })
    ```

    Konfigurasi ini:
    - `registerType: 'autoUpdate'` — SW update otomatis saat ada versi baru
    - `workbox.globPatterns` — precache aset statis saja
    - `workbox.runtimeCaching: []` — tidak cache API calls (data tetap online-only)
    - Tidak ada `navigateFallback` karena Vercel sudah punya catch-all SPA rewrite

    Avoid: Menambahkan runtimeCaching untuk `/api/*` — data tetap harus online.
  </action>
