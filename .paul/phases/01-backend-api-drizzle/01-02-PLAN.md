  <action>
    Buat src/api/routes/auth.ts dengan Express Router:

    1. **POST /login** — login endpoint:
       - Body: { phone: string, password: string }
       - Normalisasi phone dengan normalizePhone (dari src/lib/utils.ts — salin logic, jangan import dari client code)
       - Query users table via drizzle: `db.select().from(users).where(eq(users.phone, normalizedPhone)).limit(1)`
       - Validasi berurutan:
         a. User tidak ditemukan → 401 "Pengguna tidak ditemukan"
         b. !isActive → 401 "Akun dinonaktifkan"
         c. lockedUntil > Date.now() → 401 "Akun terkunci. Coba lagi dalam X menit"
         d. bcrypt.compare(password, user.passwordHash) gagal → increment failedLoginAttempts, jika >=5 set lockedUntil 15 menit, 401 "Kata sandi salah"
       - Jika sukses: reset failedLoginAttempts=0, lockedUntil=null, buat JWT dengan jose, return { token, user }
       - Gunakan `process.env.JWT_SECRET!` untuk signing key
       - JWT payload: { sub: user.id, role: user.role, phone: user.phone }
       - Expiry: 7 hari (sesuai pola "remember me" — admin tunggal, tidak perlu short expiry)

    2. **GET /me** — current user (diproteksi middleware):

<task type="auto">
  <name>Task 4: Buat JWT auth middleware</name>
  <files>src/api/middleware/auth.ts</files>
  <action>
    Buat src/api/middleware/auth.ts:

    ```typescript
    import { Request, Response, NextFunction } from 'express';
    import { jwtVerify } from 'jose';

    const secret = new TextEncoder().encode(process.env.JWT_SECRET!);

    export interface AuthRequest extends Request {
      user?: { sub: string; role: string; phone: string };
    }

    export async function requireAuth(req: AuthRequest, res: Response, next: NextFunction) {
      const header = req.headers.authorization;
      if (!header?.startsWith('Bearer ')) {
        return res.status(401).json({ error: 'Unauthorized' });
      }
      try {
        const { payload } = await jwtVerify(header.slice(7), secret);
        req.user = payload as any;
        next();
      } catch {
        return res.status(401).json({ error: 'Invalid token' });
      }
    }
    ```

    Gunakan middleware ini di route /me dan route API lainnya.
  </action>
