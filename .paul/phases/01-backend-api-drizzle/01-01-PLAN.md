<objective>
## Goal
Install Drizzle ORM + Neon DB dependencies, buat schema lengkap dari semua TypeScript types yang ada, setup koneksi ke Neon DB, dan jalankan migration untuk membuat semua tabel di database production.

## Purpose
Ini adalah fondasi seluruh migrasi. Tanpa schema dan koneksi DB yang valid, tidak ada plan berikutnya yang bisa berjalan. Plan ini mengkonversi struktur data dari TypeScript types ke PostgreSQL tables via Drizzle.

- `src/db/schema.ts` — Drizzle schema lengkap (8 tabel)
- `src/db/client.ts` — Neon DB connection singleton
- `drizzle.config.ts` — Drizzle Kit config untuk migrations
- Semua tabel terbuat di Neon DB (via `drizzle-kit push`)
- `.env` berisi DATABASE_URL yang valid

<task type="auto">
  <name>Task 2: Buat Drizzle schema dari TypeScript types</name>
  <files>src/db/schema.ts, src/db/client.ts</files>
  <action>
    Buat `src/db/client.ts`:
    ```typescript
    import { neon } from '@neondatabase/serverless';
    import { drizzle } from 'drizzle-orm/neon-http';
    import * as schema from './schema';

    const sql = neon(process.env.DATABASE_URL!);
    export const db = drizzle(sql, { schema });
    ```

    Buat `src/db/schema.ts` dengan semua tabel berdasarkan `src/types.ts`:

    Import: `pgTable, text, integer, boolean, bigint, real, jsonb, pgEnum` dari `drizzle-orm/pg-core`

    **Tabel yang dibuat (8 total):**

    1. `users` — id(text pk), name(text), phone(text unique), password_hash(text), role(text: 'admin'|'staff'|'operational'|'mitra'), is_active(boolean default true), must_change_password(boolean default false), failed_login_attempts(integer default 0), locked_until(bigint nullable)

    2. `mitras` — id(text pk), user_id(text fk→users.id), name(text), credit_limit(real nullable), is_archived(boolean default false), logo_url(text nullable)

    3. `products` — id(text pk), name(text), price(real), description(text nullable), image_url(text nullable), is_archived(boolean default false)

    4. `orders` — id(text pk), order_number(text unique), mitra_id(text fk→mitras.id), type(text: 'online'|'offline'), resi_url(text nullable), recipient_name(text nullable), recipient_phone(text nullable), recipient_address(text nullable), status(text), created_at(bigint), updated_at(bigint), has_custom_logo(boolean default false), total_amount(real default 0), total_qty(integer default 0), is_billed(boolean default false), creator_id(text nullable)

    5. `order_items` — id(text pk), order_id(text fk→orders.id), product_id(text), product_name(text), price_snapshot(real), qty(integer), is_custom_logo(boolean default false), dtf_status(text nullable), preview_url(text nullable), design_url(text nullable), preview_urls(jsonb default '[]'), design_urls(jsonb default '[]'), design_notes(text nullable)

    6. `ledgers` — id(text pk), mitra_id(text fk→mitras.id), source(text), direction(text), nominal(real), description(text), created_at(bigint), reference_id(text nullable), attachment_url(text nullable), payment_method(text nullable), reference_number(text nullable)

    7. `action_requests` — id(text pk), type(text: 'cancellation'|'return'), order_id(text fk→orders.id), mitra_id(text fk→mitras.id), reason(text), attachment_url(text nullable), status(text), credit_amount(real nullable), created_at(bigint), updated_at(bigint)

    8. `audit_logs` — id(text pk), user_id(text), action(text), details(text), created_at(bigint)

    Export semua tabel dan export types (InferSelectModel, InferInsertModel) untuk setiap tabel.

<task type="auto">
  <name>Task 3: Setup drizzle.config.ts dan jalankan migration</name>
  <files>drizzle.config.ts</files>
  <action>
    Buat `drizzle.config.ts` di root project:
    ```typescript
    import { defineConfig } from 'drizzle-kit';

    export default defineConfig({
      schema: './src/db/schema.ts',
      out: './drizzle',
      dialect: 'postgresql',
      dbCredentials: {
        url: process.env.DATABASE_URL!,
      },
    });
    ```

    Tambahkan script ke `package.json`:
    ```json
    "db:push": "drizzle-kit push",
    "db:studio": "drizzle-kit studio",
    "db:generate": "drizzle-kit generate"
    ```

    Jalankan migration dengan dotenv:
    ```bash
    npx dotenv -e .env -- drizzle-kit push
    ```

    Jika dotenv-cli belum ada: `npm install -D dotenv-cli` dulu, lalu jalankan.
  </action>
