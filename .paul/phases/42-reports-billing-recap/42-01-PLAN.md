<objective>
## Goal
Tambah tab baru **"Rekap Tagihan"** di halaman Laporan (`/reports`) yang menampilkan rekap **Produk · Qty · Harga · Total** dari pesanan yang tercatat tagihan (`isBilled = true`), dikelompokkan per produk + harga satuan, dengan filter mitra + periode (tanggal tagihan tercatat) dan ekspor PDF.

## Purpose
Admin dan mitra dapat melihat rincian produk di balik "Total Tagihan" tanpa membuka pesanan satu per satu — dasar rekonsiliasi dan penagihan (Core Value PROJECT.md: pengelolaan pesanan dan keuangan mitra secara real-time).

## Output
- Modul baru `src/components/reports/billing-recap/` — types, fungsi agregasi murni, hook, komponen tab, komponen PDF, `index.ts` sebagai public API
- `src/pages/Reports.tsx` — tab ketiga, wiring hook, cabang ekspor PDF
</objective>

- **Staff:** tab disembunyikan sepenuhnya, seperti Keuangan (dikonfirmasi user 2026-10-22). Admin dan mitra melihat tab (mitra hanya datanya sendiri — sudah di-enforce server).

<acceptance_criteria>

## AC-1: Tab Rekap Tagihan tersedia sesuai role
```gherkin
Given user login sebagai admin atau mitra
When user membuka halaman /reports
Then tab "Rekap Tagihan" muncul sebagai tab ketiga setelah "Keuangan" dan "Pesanan"
And untuk role staff tab ini tidak muncul sama sekali
And role operational tetap melihat "Akses ditolak" (tidak berubah)
```

## AC-2: Hanya pesanan yang tercatat tagihan masuk rekap
```gherkin
Given ada pesanan draft/confirmed/processing/pressing, pesanan packing/shipped (isBilled = true), dan pesanan cancelled/returned
When tab Rekap Tagihan dibuka tanpa filter
Then hanya item dari pesanan packing/shipped yang tampil
And pesanan isBilled = true yang tidak punya entri ledger source 'order' dilewati tanpa error
```

## AC-3: Pengelompokan per produk + harga satuan
```gherkin
Given produk P muncul di dua pesanan tertagih dengan harga berbeda (qty 40 @ Rp 45.000 dan qty 10 @ Rp 50.000)
When rekap dihitung
Then P tampil di dua baris terpisah: (40, Rp 45.000, Rp 1.800.000) dan (10, Rp 50.000, Rp 500.000)
And baris TOTAL = jumlah Qty dan jumlah Total seluruh baris
And baris diurutkan nama produk A–Z lalu harga naik
```

## AC-4: Periode mengikuti tanggal tagihan tercatat
```gherkin
Given pesanan dibuat 28 Sep tetapi masuk Packing (entri ledger debit dibuat) pada 2 Okt
When filter periode diisi 1–5 Okt
Then pesanan itu ikut rekap; dengan filter 25–30 Sep ia tidak ikut
And batas Tanggal Akhir inklusif sampai 23:59:59 hari tersebut
```

## AC-5: Filter mitra dan isolasi data
```gherkin
Given admin membuka tab Rekap Tagihan
When admin memilih mitra tertentu (atau "Semua Mitra")
Then rekap hanya berisi pesanan mitra itu (atau gabungan semua mitra)

Given user mitra membuka tab Rekap Tagihan
Then tidak ada dropdown mitra dan rekap hanya berisi pesanan miliknya
```

## AC-6: Selaras dengan tab Keuangan
```gherkin
Given mitra dan rentang tanggal yang sama dipilih di tab Keuangan dan tab Rekap Tagihan
And pada rentang itu tidak ada entri debit sumber MANUAL
When kedua nilai dibandingkan
Then "Total Tagihan" di Rekap Tagihan sama dengan "Total Tagihan" di Keuangan
```

## AC-7: Empty state dan ekspor PDF
```gherkin
Given tab Rekap Tagihan memiliki minimal 1 baris
When user klik "Cetak PDF" lalu "Unduh PDF"
Then PDF terunduh berisi judul, periode, mitra, ringkasan, tabel, dan baris TOTAL yang sama dengan tampilan layar

Given filter tidak menghasilkan baris
Then tampil empty state "Belum ada pesanan tertagih"
And tombol "Cetak PDF" nonaktif selama tab ini aktif
```
