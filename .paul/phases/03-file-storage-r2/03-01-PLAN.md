<objective>
## Goal
Migrasi file upload dari base64/localStorage ke Cloudflare R2 — FileUpload.tsx dan MultiFileUpload.tsx memanggil POST /api/upload dan menyimpan R2 URL, bukan base64 string.

## Purpose
Phase 2 selesai dengan data di Neon DB, tapi file masih base64 di localStorage. Phase 3 menyelesaikan migrasi storage: semua file (logo, foto produk, desain DTF, resi, bukti bayar) tersimpan di R2 dan dapat diakses via URL publik — bukan tertanam sebagai data:image/... di database.

## Output
- `POST /api/upload` — menerima raw file body, upload ke R2, return `{ url: string }`
- `api.upload.file(file)` di `src/lib/api.ts`
- `FileUpload.tsx` — onChange dipanggil dengan R2 URL (bukan base64)
- `MultiFileUpload.tsx` — onChange dipanggil dengan R2 URL array (bukan base64 array)
</objective>

    **A. Buat src/api/routes/upload.ts:**

    ```typescript
    import express, { type Request, type Response } from 'express';
    import { S3Client, PutObjectCommand } from '@aws-sdk/client-s3';
    import { requireAuth } from '../middleware/auth.ts';

    const router = express.Router();
    router.use(requireAuth);

    const s3 = new S3Client({
      region: 'auto',
      endpoint: `https://${process.env.R2_ACCOUNT_ID}.r2.cloudflarestorage.com`,
      credentials: {
        accessKeyId: process.env.R2_ACCESS_KEY_ID!,
        secretAccessKey: process.env.R2_SECRET_ACCESS_KEY!,
      },
    });

    router.post('/', express.raw({ type: '*/*', limit: '10mb' }), async (req: Request, res: Response) => {
      try {
        const contentType = req.headers['content-type'] || 'application/octet-stream';
        const originalName = (req.headers['x-file-name'] as string) || 'upload';
        const ext = originalName.split('.').pop()?.toLowerCase() || 'bin';
        const key = `uploads/${Date.now()}-${crypto.randomUUID().slice(0, 8)}.${ext}`;

        await s3.send(new PutObjectCommand({
          Bucket: process.env.R2_BUCKET_NAME!,
          Key: key,
          Body: req.body as Buffer,
          ContentType: contentType,
        }));

        const publicUrl = `${process.env.R2_PUBLIC_URL}/${key}`;
        return res.json({ url: publicUrl });
      } catch (err: any) {
        return res.status(500).json({ error: err.message });
      }
    });

    export default router;
    ```

    Catatan: `express.raw()` di-apply per-route agar tidak konflik dengan global `express.json()` di index.ts.

    **B. Tambah route di src/api/index.ts (setelah auditLogsRouter):**

    ```typescript

    // ...
    app.use('/api/upload', uploadRouter);
    ```

    **C. Tambah api.upload di src/lib/api.ts (setelah auditLogs block):**

    ```typescript
    upload: {
      file: (file: File) => {
        const token = getToken();
        return fetch(`${BASE}/upload`, {
          method: 'POST',
          headers: {
            'Content-Type': file.type,
            'X-File-Name': file.name,
            ...(token ? { Authorization: `Bearer ${token}` } : {}),
          },
          body: file,
        }).then(async res => {
          if (!res.ok) {
            const err = await res.json().catch(() => ({ error: res.statusText }));
            throw new Error(err.error || res.statusText);
          }
          return res.json() as Promise<{ url: string }>;
        });
      },
    },
    ```
