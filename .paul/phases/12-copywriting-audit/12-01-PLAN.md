<objective>
## Goal
Audit komprehensif seluruh copy UI aplikasi REMA v2.1 — inventarisasi semua teks yang tampil ke user, identifikasi masalah, dan produksi COPY-AUDIT.md dengan proposed improvements siap review.

## Purpose
Copy yang inconsistent, terlalu panjang, atau tidak standar industri membuat UI terkesan tidak profesional. Audit ini membangun baseline yang bisa langsung dieksekusi pada Plan 12-02 tanpa perlu membaca ulang source.

## Output
`.paul/phases/12-copywriting-audit/COPY-AUDIT.md` berisi:
- Inventaris semua copy element per file
- Temuan: inconsistency, verbosity, non-standard phrasing
- Proposed copy improvement per item
- Rekomendasi icon-only (area yang tidak butuh teks)
</objective>

## AC-1: Inventaris Lengkap
```gherkin
Given semua file source UI telah dibaca
When audit selesai
Then COPY-AUDIT.md mendokumentasikan setiap copy element dari semua 19 file:
     page titles, section headers, button labels, form labels, placeholders,
     toast messages, confirmation dialog text, empty states, error messages,
     tooltip/helper text, dan navigation labels
```

## AC-2: Temuan Terstruktur
```gherkin
Given inventaris selesai
When setiap item dievaluasi
Then setiap temuan dikategorikan dengan:
     - [VERBOSE] — teks terlalu panjang, bisa dipersingkat
     - [INCONSISTENT] — pola berbeda untuk hal yang sama
     - [NON-STANDARD] — tidak sesuai konvensi industri SaaS Indonesia
     - [ICON-ONLY] — area yang cukup dengan icon tanpa teks
     - [OK] — sudah baik, tidak perlu diubah
```

## AC-3: Proposed Improvements Siap Eksekusi
```gherkin
Given temuan terdokumentasi
When proposed improvements ditulis
Then setiap item [VERBOSE/INCONSISTENT/NON-STANDARD] memiliki:
     - Current: teks saat ini (exact string dari kode)
     - Proposed: teks pengganti yang lebih baik
     - Reason: alasan singkat 1 baris
     Dan format output memungkinkan Plan 12-02 langsung find-and-replace
     tanpa perlu membaca ulang source
```

  <action>
    Kompilasi seluruh temuan dari Task 1 dan Task 2 menjadi dokumen COPY-AUDIT.md yang terstruktur.

    Format dokumen:

    ```
    # COPY-AUDIT.md — REMA v2.1 Copywriting Audit

    ## Ringkasan Eksekutif
    - Total copy elements ditemukan: N
    - Breakdown: N [OK] / N [VERBOSE] / N [INCONSISTENT] / N [NON-STANDARD] / N [ICON-ONLY]
    - File dengan masalah terbanyak: ...
    - Tema masalah utama: ...

    ## Panduan Copy Standard
    Prinsip yang digunakan sebagai acuan audit:
    1. Tombol aksi: verb singkat ("Simpan", bukan "Simpan Data")
    2. Pesan toast: "Berhasil [verb]" / "[Noun] gagal [verb]"
    3. Konfirmasi: title = nama aksi, body = konsekuensi singkat
    4. Label form: noun tanpa titik dua (styling handle CSS)
    5. Placeholder: contoh format atau petunjuk isi, bukan repeat label
    6. Empty state: "[Noun] belum ada" atau aksi proaktif
    7. Error: spesifik, bukan generik ("Gagal memuat")

    ## Temuan Per File

    ### [nama file]
    | Element | Current | Category | Proposed | Reason |
    |---------|---------|----------|----------|--------|
    | Button: submit | "Simpan Data Pesanan" | [VERBOSE] | "Simpan" | Konteks sudah jelas dari modal title |
    | Toast: success | "Berhasil masuk" | [OK] | — | Sudah ringkas dan standar |

    ## Rekomendasi Icon-Only
    Area yang disarankan cukup dengan icon tanpa teks label:
    - [nama komponen/lokasi]: [alasan]

    ## Summary Perubahan untuk Plan 12-02
    Total perubahan yang perlu diimplementasi: N file, N string
    ```

    Pastikan setiap baris di tabel "Temuan Per File" bisa langsung jadi instruksi find-and-replace
