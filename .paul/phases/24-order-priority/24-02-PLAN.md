## Goal
Buat halaman Prioritas Pesanan yang menampilkan daftar prioritas aktif, modal tambah prioritas dengan dropdown pesanan aktif + catatan, quota warning profesional, tombol hapus (mitra own only), dan nav link Zap di semua role. Tambahkan field Priority Limit di form edit mitra untuk admin.

Frontend yang memungkinkan mitra mengelola prioritas pesanan mereka dengan UX yang jelas — termasuk feedback profesional saat kuota habis — serta memberikan visibility ke semua role tentang pesanan yang diprioritaskan.

- Halaman baru `/priority` (Prioritas Pesanan) — semua role akses
- Modal tambah prioritas + quota warning modal
- Nav link Zap di sidebar semua role
- Field Priority Limit di form edit Mitra (admin only)
</objective>

    ```
        ├── Icon AlertTriangle berwarna amber

        └── Button "Mengerti" (close modal)
    ```

    **Data loading:**
    ```typescript
    const [priorities, setPriorities] = useState<OrderPriority[]>([]);
    const [myOrders, setMyOrders] = useState<Order[]>([]); // untuk dropdown, mitra only
    const [mitra, setMitra] = useState<Mitra | null>(null); // quota info
    const [loading, setLoading] = useState(true);

    useEffect(() => {
      const load = async () => {
        const data = await api.priorities.list();
        setPriorities(data);
        if (user?.role === 'mitra') {
          const allOrders = await api.orders.list();
          const activeStatuses = ['confirmed', 'processing', 'pressing'];
          const activeOrders = allOrders.filter(o => activeStatuses.includes(o.status));
          // Exclude orders yang sudah di-prioritize
          const prioritizedOrderIds = new Set(data.map(p => p.orderId));
          setMyOrders(activeOrders.filter(o => !prioritizedOrderIds.has(o.id)));
          const allMitras = await api.mitras.list();
          // Find mitra milik user ini — match by ordering sesuai yang ada
          // Untuk sekarang ambil dari priorities data (mitraId) atau dari mitras list
          setMitra(allMitras.find(m => /* userId match */ true) || null);
        }
        setLoading(false);
      };
      load();
    }, [user]);
    ```

    **Catatan penting untuk mitra lookup:**
    Frontend tidak punya direct cara lookup mitra by userId tanpa endpoint khusus.
    Solusi: setelah berhasil tambah priority, data dari API response sudah punya mitraId.
    Untuk quota display: gunakan data dari response error QUOTA_EXCEEDED (current, limit).
    Flow: klik "Tambah Prioritas" → jika API return 403 QUOTA_EXCEEDED → tutup modal tambah → tampilkan QuotaWarningModal dengan data dari error response.

    **Tambah priority flow:**
    ```
    klik "Tambah Prioritas"
    → jika priorities.length == 0 atau ada slot: buka AddPriorityModal
    → submit: api.priorities.create({ orderId, notes })
      → success: refresh list, tutup modal, toast "Pesanan berhasil ditambahkan ke daftar prioritas"
      → error QUOTA_EXCEEDED: tutup AddPriorityModal, buka QuotaWarningModal dengan { current, limit } dari error
      → error lain: toast.error(err.message)
    ```

    **Hapus priority:**

    - Sebelum hapus: tampilkan useConfirm dialog "Hapus pesanan ini dari daftar prioritas?"
    - Setelah hapus: refresh list, toast "Pesanan dihapus dari daftar prioritas"

    - Desktop: table dengan sticky header
