<task type="auto">
  <name>Task 2: API route priorities.ts — GET, POST, DELETE</name>
  <files>src/api/routes/priorities.ts</files>
  <action>
    Buat file baru `src/api/routes/priorities.ts`. Ikuti pola routes yang ada (import express, db, requireAuth).

    **GET /**
    - Semua role boleh akses
    - Query: SELECT op.*, o.order_number, o.total_qty, o.status, m.name AS mitra_name
      FROM order_priorities op
      JOIN orders o ON op.order_id = o.id
      JOIN mitras m ON op.mitra_id = m.id
      WHERE o.status IN ('confirmed', 'processing', 'pressing')
      ORDER BY op.created_at ASC
    - Gunakan Drizzle: `db.select({...}).from(orderPriorities).innerJoin(orders, ...).innerJoin(mitras, ...).where(inArray(orders.status, ACTIVE_STATUSES))`
    - Konstanta: `const ACTIVE_STATUSES = ['confirmed', 'processing', 'pressing'] as const`

    **POST /**
    - Role check: `if (req.user.role !== 'mitra') return res.status(403).json({ error: 'FORBIDDEN' })`
    - Lookup mitra by userId: `await db.select().from(mitras).where(eq(mitras.userId, req.user.sub)).limit(1)`
    - Jika mitra tidak ditemukan: return 404
    - Validasi order: order harus ada, order.mitraId === mitra.id, order.status in ACTIVE_STATUSES
    - Cek duplikat: orderId belum ada di order_priorities aktif (join dengan orders filter ACTIVE_STATUSES)
    - Quota check:
      ```
      const activeCount = await db.select().from(orderPriorities)
        .innerJoin(orders, eq(orderPriorities.orderId, orders.id))
        .where(and(
          eq(orderPriorities.mitraId, mitra.id),
          inArray(orders.status, ACTIVE_STATUSES)
        ))
      if (activeCount.length >= mitra.priorityLimit) {
        return res.status(403).json({ error: 'QUOTA_EXCEEDED', current: activeCount.length, limit: mitra.priorityLimit })
      }
      ```
    - Insert: `{ id: crypto.randomUUID(), orderId, mitraId: mitra.id, notes: body.notes || null, createdAt: Date.now(), createdBy: req.user.sub }`
    - Return 201 dengan entry baru

    **DELETE /:id**
    - Role check: `if (req.user.role !== 'mitra') return res.status(403).json({ error: 'FORBIDDEN' })`
    - Lookup mitra by userId (sama seperti POST)
    - Cari priority entry by id
    - Ownership check: `if (entry.mitraId !== mitra.id) return res.status(403).json({ error: 'FORBIDDEN' })`
    - Delete entry
    - Return 204

    Avoid: jangan expose endpoint PUT/PATCH — priorities hanya create atau delete.
    Avoid: jangan skip ownership check pada DELETE.
  </action>
  <verify>npm run lint 0 errors; import/export tidak ada error TypeScript</verify>
