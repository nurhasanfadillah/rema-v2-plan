Redesign halaman Login agar tampilan dan layout persis mengikuti referensi desain mobile-first, termasuk: latar navy gelap, logo centered, input bergaya label-dalam-field + ikon kotak biru, checkbox "Ingat saya", security badge card, dan footer lengkap — tanpa elemen Face ID & Login dengan PIN.

## AC-1: Layout Mobile-First Single Column
```gherkin
Given pengguna membuka halaman /login
When halaman dirender di layar mobile (≤768px) maupun desktop
Then tampil single-column centered, latar navy gelap (#0a1628), tanpa split-panel kiri
```

## AC-2: Header Logo & Branding
```gherkin
Given halaman login terbuka
When melihat bagian atas
Then tampil logo "REMA-V2" (teks REMA putih, -V2 biru elektrik), di bawahnya subtitle "Manajemen Produksi & Finance", lalu heading "Selamat Datang Kembali" dan deskripsi singkat
```

## AC-3: Input Fields — Gaya Kotak Ikon + Label Floating
```gherkin
Given form login dirender
When melihat input Nomor Telepon dan Kata Sandi
Then setiap field memiliki: ikon di kotak biru kiri (rounded), label kecil di atas nilai, border rounded-xl; Nomor Telepon menampilkan checkmark hijau saat terisi valid; Kata Sandi punya toggle show/hide di kanan
```

## AC-4: Row "Ingat Saya" + "Lupa Sandi?"
```gherkin
Given form login dirender
When melihat area di bawah input password
Then tampil "Lupa sandi?" rata kanan di baris sendiri, dan di bawahnya row dengan checkbox "Ingat saya" saja (tanpa Face ID, tanpa Login dengan PIN)
```

## AC-5: Tombol Masuk CTA
```gherkin
Given form login dirender
When melihat tombol submit
Then tombol "Masuk →" full-width, biru elektrik, rounded-xl, dengan loading spinner saat submit; fungsionalitas login tetap bekerja sama
```

## AC-6: Security Badge & Footer
```gherkin
Given halaman login dirender
When scroll ke bawah tombol Masuk
Then tampil: divider "atau", card "Koneksi terenkripsi" dengan badge "Aman" hijau, row "Syarat & Ketentuan | Kebijakan Privasi", row "Butuh bantuan? Hubungi tim support kami" dengan teks "Versi 2.0.0 >" di kanan
```
