Header halaman detail pesanan menampilkan nama mitra secara inline setelah order number — format `{orderNumber} — {mitraName}` — sehingga admin/staff/operational/mitra langsung tahu pesanan ini milik mitra siapa tanpa scroll.

<acceptance_criteria>

## AC-1: Nama mitra tampil inline di header
```gherkin
Given user membuka halaman `/orders/:id` untuk pesanan yang mitraId-nya valid
When komponen `OrderDetail` merender header
Then judul `h1` menampilkan `{order.orderNumber} — {orderMitra.name}` sebagai satu baris teks
And separator adalah em dash (`—`, U+2014) diapit spasi
And styling `h1` tidak berubah (tetap `text-xl sm:text-2xl font-bold text-white tracking-tighter font-mono`)
And baris subline di atasnya (`{tanggal} · {id 8-char}`) tetap tidak berubah
And behavior berlaku sama untuk semua role (admin, staff, operational, mitra)
```

## AC-2: Fallback aman saat data mitra tidak ditemukan
```gherkin
Given pesanan tidak memiliki mitra yang cocok di daftar `mitras` (data anomali — mitraId dangling)
When komponen `OrderDetail` merender header
Then judul `h1` hanya menampilkan `{order.orderNumber}` tanpa separator maupun teks kosong setelahnya
And tidak melempar runtime error (tidak ada akses `undefined.name`)
```
