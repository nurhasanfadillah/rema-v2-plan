<task type="auto">
  <name>Task 1: Tambah tabel priceCalculations ke schema.ts</name>
  <files>src/db/schema.ts</files>
  <action>
    Tambah tabel baru `priceCalculations` di akhir definisi tabel (sebelum exported types):

    ```ts
    export const priceCalculations = pgTable('price_calculations', {
      id: text('id').primaryKey(),
      userId: text('user_id').notNull(),
      productId: text('product_id'),            // null = input manual, isi = capture dari produk (bukan FK)
      productName: text('product_name').notNull(), // snapshot nama — manual atau dari produk
      hargaPokok: real('harga_pokok').notNull(),
      qty: integer('qty').notNull().default(1),
      margin: real('margin').notNull(),
      adminMP: real('admin_mp').notNull(),
      additionals: jsonb('additionals').$type<Array<{ label: string; value: number; type: 'nominal' | 'persen' }>>().notNull().default([]),
      hargaJual: real('harga_jual').notNull(),
      hargaMP: real('harga_mp').notNull(),
      hargaFinals: jsonb('harga_finals').$type<number[]>().notNull().default([]),
      createdAt: bigint('created_at', { mode: 'number' }).notNull(),
    });
    ```

    Catatan penting:
    - `productId` tidak pakai `.references()` — sengaja tidak ada FK ke tabel products.
      Kalkulasi harus tetap valid meskipun produk dihapus atau diubah.
    - `productName` adalah snapshot: diisi manual oleh user atau di-capture dari nama produk saat dipilih.
    - `qty` default 1 — dipakai untuk kalkulasi total (harga × qty) di frontend.

    Tambah juga exported types di bagian bawah:
    ```ts
    export type PriceCalculation = InferSelectModel<typeof priceCalculations>;
    export type NewPriceCalculation = InferInsertModel<typeof priceCalculations>;
    ```
  </action>
  <verify>npm run lint — tidak ada TypeScript error di schema.ts</verify>
  <done>AC-1 satisfied: schema siap untuk db:push</done>
</task>

<task type="auto">
  <name>Task 2: Buat API route price-calculations.ts</name>
  <files>src/api/routes/price-calculations.ts</files>
  <action>
    Buat file baru. Pattern ikuti priorities.ts.

    **Role check:** Hanya `admin` dan `mitra` yang boleh akses semua endpoint. Di awal setiap handler:
    ```ts
    if (!['admin', 'mitra'].includes(req.user.role)) {
      return res.status(403).json({ error: 'FORBIDDEN' });
    }
    ```

    **GET /**: Query semua rows dimana `userId = req.user.sub`, order by `createdAt DESC`.

    **POST /**: Terima body:
    ```ts
    { productId?, productName, hargaPokok, qty, margin, adminMP, additionals, hargaJual, hargaMP, hargaFinals }
    ```
    Validasi: `productName`, `hargaPokok`, `margin`, `adminMP`, `hargaJual`, `hargaMP` wajib ada.
    `qty` default ke 1 jika tidak dikirim atau < 1.
    Insert dengan `id: crypto.randomUUID()`, `userId: req.user.sub`, `createdAt: Date.now()`.
    Response 201 dengan data inserted.

    **DELETE /:id**: Query row by id. Jika tidak ditemukan → 404. Jika `row.userId !== req.user.sub` → 403. Hapus dan response 204.

    Import: `import { priceCalculations } from '../../db/schema.ts'`
    Import operator: `eq, desc` dari `drizzle-orm`
  </action>
  <verify>npm run lint — tidak ada TypeScript error di price-calculations.ts</verify>
  <done>AC-2, AC-3, AC-4, AC-5 satisfied: semua endpoint terdefinisi dengan ownership + role check</done>
</task>
