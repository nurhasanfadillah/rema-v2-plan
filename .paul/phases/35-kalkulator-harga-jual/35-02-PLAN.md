## Goal
Buat halaman `/calculator` dengan form kalkulator harga jual interaktif — dua mode input produk, kalkulasi bertahap live, hitung per unit dan total (× qty), simpan ke DB, dan panel riwayat milik sendiri.

Admin dan mitra bisa menghitung harga jual dari harga pokok dengan margin, biaya marketplace, dan biaya tambahan opsional — hasilnya bisa disimpan dan dilihat kembali.

- `src/lib/api.ts` — tambah `api.priceCalculations.*`
- `src/App.tsx` — route `/calculator`
- `src/components/Layout.tsx` — nav link (admin + mitra)
</objective>

<task type="auto">
  <name>Task 2: Buat halaman Calculator.tsx</name>
  <files>src/pages/Calculator.tsx</files>
  <action>
    Buat halaman baru. Ikuti pola UI halaman existing (page-header, card-sm, btn-primary dari index.css).

    **State form:**
    ```ts
    productInputMode: 'select' | 'manual'   // default 'select'
    selectedProductId: string               // hanya untuk mode 'select'
    productName: string                     // snapshot nama — dari produk atau diketik manual
    hargaPokok: number
    qty: number                             // default 1, min 1
    margin: number                          // default 30
    adminMP: number                         // default 14
    additionals: Array<{ label: string; value: number; type: 'nominal' | 'persen' }>  // max 4
    ```

    **Kalkulasi (computed setiap render — tidak perlu useMemo kecuali performa bermasalah):**
    ```ts
    const hargaJual = margin > 0 && margin < 100
      ? hargaPokok / (1 - margin / 100)
      : hargaPokok;

    const hargaMP = adminMP > 0 && adminMP < 100
      ? hargaJual / (1 - adminMP / 100)
      : hargaJual;

    const hargaFinals = additionals.reduce<number[]>((acc, item, i) => {
      const base = i === 0 ? hargaMP : acc[i - 1];
      const result = item.type === 'persen' && item.value > 0 && item.value < 100
        ? base / (1 - item.value / 100)
        : base + item.value;
      return [...acc, result];
    }, []);

    // Total = harga × qty
    const safeQty = Math.max(1, qty);
    ```

    **Format tampilan angka:**
    ```ts
    // Helper lokal di file ini
    const fmt = (n: number) => Math.round(n).toLocaleString('id-ID');
    ```

    **Layout halaman:**

    1. **Header:** judul "Kalkulator Harga Jual", subtitle "Hitung harga jual, marketplace, dan biaya tambahan"

    2. **Card Form (kiri/atas):**

       *Toggle mode input produk:*
       - Dua tombol: "Pilih dari Produk" | "Input Manual"
       - Mode `select`: tampilkan dropdown `<select>` daftar produk (load via `api.products.list()` saat mount, filter `!p.isArchived`). onChange → set `productName = p.name`, `hargaPokok = p.price`, `selectedProductId = p.id`.
       - Mode `manual`: tampilkan `<input type="text">` untuk Nama Produk + `<input type="number">` untuk Harga Pokok. `selectedProductId = null` di kedua mode (set null saat switch ke manual).
       - Saat switch mode, reset `productName = ''`, `hargaPokok = 0`, `selectedProductId = ''`.

       *Input fields:*
       - Harga Pokok (number) — di mode `select` sudah terisi dari produk tapi tetap bisa diubah
       - Qty (number, min 1, default 1)
       - Margin % (number, 0–99, default 30):
         Tampilkan warning kuning di bawah input jika `margin > 0 && margin < 20`:
         ```
         ⚠️ Margin di bawah 20% kurang sehat — laba terlalu tipis untuk menutup biaya operasional.
         ```
       - Admin MP % (number, 0–99, default 14)

       *Section "Biaya Tambahan":*
       - List `additionals` + tombol "+ Tambah Biaya" (sembunyikan jika `length >= 4`)
       - Per row: input label (text, placeholder "mis. Ongkir"), input nilai (number), toggle "Nominal" / "%" (type), tombol hapus (X / Trash2 icon)

    3. **Card Output (kanan/bawah) — live update:**

       Tampilkan tabel atau stack card dengan dua kolom: "Per Unit" dan "Total (×qty)":

       | Label | Per Unit | Total |
       |---|---|---|
       | Harga Jual | Rp {fmt(hargaJual)} | Rp {fmt(hargaJual * safeQty)} |
       | Harga Marketplace | Rp {fmt(hargaMP)} | Rp {fmt(hargaMP * safeQty)} |
       | Harga Final 1 (label) | Rp {fmt(hargaFinals[0])} | Rp {fmt(hargaFinals[0] * safeQty)} |
       | ... dst |

       Baris Harga Final hanya tampil jika `additionals.length > 0`.
       Label baris Harga Final = "Harga Final {i+1}" + (jika `additionals[i].label` tidak kosong: ` — {label}`).

    4. **Tombol "Simpan Kalkulasi"** (btn-primary):
       - Validasi: `productName` tidak kosong, `hargaPokok > 0`.
       - Kirim: `api.priceCalculations.create({ productId: selectedProductId || null, productName, hargaPokok, qty: safeQty, margin, adminMP, additionals, hargaJual: Math.round(hargaJual), hargaMP: Math.round(hargaMP), hargaFinals: hargaFinals.map(Math.round) })`
       - Setelah berhasil: reload riwayat via `api.priceCalculations.list()`.

    5. **Section "Riwayat Kalkulasi":**
       - Load saat mount via `api.priceCalculations.list()`.
       - Kartu per item menampilkan: nama produk, `qty × harga pokok → harga final terakhir` (atau harga MP jika tidak ada additionals), tanggal (`new Date(item.createdAt).toLocaleDateString('id-ID')`).
       - Tombol hapus (ikon Trash2) per item → `api.priceCalculations.remove(id)` → filter dari state.

    **Import produk:** gunakan `api.products.list()` yang sudah ada di api.ts.
    Hindari abstraksi baru — ikuti pola useState + useEffect dari halaman existing.
