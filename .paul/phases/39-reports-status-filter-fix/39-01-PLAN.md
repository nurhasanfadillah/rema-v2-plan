<objective>
## Goal
Filter status di halaman Laporan (tab Pesanan) menampilkan seluruh 9 status alur pesanan — tambahkan `pressing`, `packing`, `cancelled` yang saat ini hilang, dan samakan label dengan `STATUS_LABELS` di `OrderDetail.tsx`.

## Purpose
User tidak bisa memfilter/menganalisis laporan pesanan untuk tahap Press Sablon, Sedang Packing, dan Dibatalkan karena filter dropdown tidak menyediakan opsinya. Ini bug pada halaman Laporan yang secara langsung menghambat aktivitas monitoring admin/mitra.

## Output
Perubahan pada `src/pages/Reports.tsx` — blok `<select>` filter status di tab Pesanan berisi 10 opsi (1 "Semua" + 9 status alur) dengan label bahasa Indonesia konsisten.
</objective>

<acceptance_criteria>

## AC-1: Filter status lengkap 9 opsi
```gherkin
Given admin membuka halaman Laporan dan pindah ke tab "Pesanan"
When user mengklik dropdown "Status"
Then dropdown menampilkan 10 opsi berurut: Semua, Draft, Menunggu Konfirmasi, Dikonfirmasi, Proses Produksi, Press Sablon, Sedang Packing, Terkirim/Selesai, Pesanan Retur, Dibatalkan
```

## AC-2: Filter berfungsi untuk 3 status baru
```gherkin
Given terdapat order dengan status `pressing`, `packing`, dan `cancelled` di database
When user memilih salah satu status tersebut di dropdown filter
Then hanya order dengan status matching yang masuk kalkulasi totalQty, totalSubtotal, productRecap, dan chart
```

## AC-3: Label konsisten dengan Order Detail
```gherkin
Given user melihat status filter di halaman Laporan
When membandingkan dengan label status di halaman Order Detail
Then label untuk setiap status (draft, waiting_confirmation, confirmed, processing, pressing, packing, shipped, returned, cancelled) identik dengan `STATUS_LABELS` di src/pages/orders/OrderDetail.tsx:21-31
```
