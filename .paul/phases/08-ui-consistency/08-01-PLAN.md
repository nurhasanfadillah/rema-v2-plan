<objective>
## Goal
Tambah `@layer components` di `src/index.css` berisi utility classes untuk button, card, typography, dan page layout — sebagai fondasi sistem desain yang konsisten.

Audit menemukan 40+ hardcoded button styles, heading sizes tidak konsisten (text-lg s/d text-3xl), dan card padding bervariasi liar. Dengan mendefinisikan utility classes di satu tempat, plan 08-02 dan 08-03 bisa mengganti hardcode tersebut tanpa mengubah visual.

## Output
- `src/index.css` bertambah section `@layer components` di bagian bawah
- Tersedia: `.btn-primary`, `.btn-secondary`, `.btn-danger`, `.btn-ghost`, `.card`, `.page-title`, `.section-title`, `.label-xs`, `.page-wrapper`
</objective>

  <name>Task 1: Tambah @layer components ke src/index.css</name>

  <action>
    Tambahkan section berikut di bagian paling bawah src/index.css (setelah .no-scrollbar block):

    ```css
    /* --- COMPONENT UTILITY SYSTEM --- */
    @layer components {

      /* === BUTTONS === */
      /* Base — shared by semua varian button */
      .btn {
        @apply inline-flex items-center justify-center gap-2 rounded-xl font-bold
               text-[13px] transition-all duration-200 active:scale-95
               disabled:opacity-50 disabled:pointer-events-none;
      }

      /* Ukuran default (md) */
      .btn-md { @apply px-4 py-2.5; }
      .btn-sm { @apply px-3 py-2 text-[11px]; }
      .btn-lg { @apply px-5 py-3 text-[14px]; }

      /* Varian warna */
      .btn-primary {
        @apply btn btn-md bg-blue-600 hover:bg-blue-500 text-white shadow-md
               shadow-blue-600/20;
      }
      .btn-secondary {
        @apply btn btn-md bg-slate-800 hover:bg-slate-700 text-slate-200
               border border-slate-700/60;
      }
      .btn-danger {
        @apply btn btn-md bg-red-500/10 hover:bg-red-500 text-red-400
               hover:text-white border border-red-500/20;
      }
      .btn-ghost {
        @apply btn btn-md bg-transparent hover:bg-slate-800/60 text-slate-400
               hover:text-white;
      }
      .btn-success {
        @apply btn btn-md bg-emerald-600 hover:bg-emerald-500 text-white
               shadow-md shadow-emerald-600/20;
      }

      /* === CARDS === */
      .card {
        @apply bg-slate-900/60 border border-slate-800/60 rounded-2xl
               shadow-lg p-5 sm:p-6;
      }
      .card-sm {
        @apply bg-slate-900/60 border border-slate-800/60 rounded-xl
               shadow-md p-4;
      }
      .card-flat {
        @apply bg-slate-900/40 border border-slate-800/40 rounded-2xl p-5 sm:p-6;
      }

      /* === TYPOGRAPHY === */
      /* Judul halaman utama (h1 setara) */
      .page-title {
        @apply text-xl sm:text-2xl font-bold tracking-tight text-white font-display;
      }
      /* Judul section dalam halaman (h2 setara) */
      .section-title {
        @apply text-base font-bold tracking-tight text-white font-display;
      }
      /* Label kecil uppercase — untuk kolom tabel, grup field */
      .label-xs {
        @apply text-[10px] font-bold uppercase tracking-widest text-slate-500;
      }
      /* Teks deskripsi / subtitle */
      .text-muted {
        @apply text-[12px] text-slate-500 leading-relaxed;
      }

      /* === PAGE LAYOUT === */
      /* Wrapper padding konsisten untuk semua halaman */
      .page-wrapper {
        @apply p-4 sm:p-6 md:p-8 space-y-6;
      }
      /* Header row di atas halaman (title + action button) */
      .page-header {
        @apply flex items-center justify-between gap-4 flex-wrap;
      }
    }
    ```

    Pastikan ditambahkan SETELAH semua selector CSS yang ada, tidak di tengah-tengah.
    Jangan ubah kode yang sudah ada.
