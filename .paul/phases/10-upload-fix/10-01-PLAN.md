<objective>
## Goal
Fix POST /api/upload yang mengembalikan HTTP 500 di production (Vercel), sehingga semua upload file (logo mitra, foto produk, bukti resi, bukti bayar) berfungsi kembali.

## Purpose
Bug kritis ini memblokir semua fitur yang membutuhkan upload file di production https://redone.my.id. Tanpa fix ini, admin tidak bisa menambah logo mitra, foto produk, atau bukti pembayaran.

## Output

- Upload file berhasil ke Cloudflare R2 dan mengembalikan URL publik
</objective>

## Root Cause Analysis
Handler saat ini (baris 43–46) membaca body menggunakan async iterator:
```typescript
for await (const chunk of req) {
  chunks.push(Buffer.from(chunk));
}
```
Di Vercel serverless, `req` bukan stream yang bisa di-iterate secara async — Vercel sudah mem-buffer body sebelum sampai ke Express. `for await` melempar exception yang ditangkap catch block → return 500.

Fix: gunakan `express.raw({ type: '*/*', limit: '10mb' })` sebagai route-level middleware sehingga `req.body` berisi `Buffer` langsung.


    3. Pertahankan check `if (body.length === 0)` — sudah ada di baris 48.

    4. Di catch block (baris 61–63), tambah `console.error('[upload] Error:', err)` sebelum `return res.status(500)...` agar error lengkap muncul di Vercel Function Logs.

    Hindari: mengubah logika `initS3()`, mengubah key generation, mengubah response format `{ url }`.

    Hasil akhir blok utama handler:
    ```typescript
    router.post('/', express.raw({ type: '*/*', limit: '10mb' }), async (req: Request, res: Response) => {
      try {
        const { s3, bucketName, publicUrl, missing } = initS3();
        if (missing.length > 0) {
          return res.status(500).json({ error: `Missing R2 env vars: ${missing.join(', ')}` });
        }

        const contentType = req.headers['content-type'] || 'application/octet-stream';
        const originalName = (req.headers['x-file-name'] as string) || 'upload';
        const ext = originalName.split('.').pop()?.toLowerCase() || 'bin';
        const key = `uploads/${Date.now()}-${crypto.randomUUID().slice(0, 8)}.${ext}`;

        const body = req.body as Buffer;

        if (body.length === 0) {
          return res.status(400).json({ error: 'Empty request body' });
        }

        await s3.send(new PutObjectCommand({
          Bucket: bucketName,
          Key: key,
          Body: body,
          ContentType: contentType,
        }));

        const url = `${publicUrl}/${key}`;
        return res.json({ url });
      } catch (err: any) {
        console.error('[upload] Error:', err);
        return res.status(500).json({ error: err.message });
      }
    });
    ```
