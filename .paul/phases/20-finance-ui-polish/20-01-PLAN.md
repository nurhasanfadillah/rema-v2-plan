<objective>
## Goal
Polish UI halaman Keuangan: perbaiki typography label summary card (uppercase → title case), persingkat subtitle, tambah colored left-border pada mobile journal cards by direction, dan perkuat visual secondary button "Tagihan Manual".

## Purpose
Typography uppercase yang dominan terasa kaku dan outdated untuk finance dashboard. Mobile cards terlalu seragam — tidak ada visual cue langsung antara debit (tagihan) vs kredit (bayar). Secondary button terlalu flat sehingga tidak ada hierarchy visual yang jelas antara dua CTA utama.

## Output
- `src/pages/Finance.tsx` — 4 perubahan UI:
  1. Label summary card: title case + normal tracking
  2. Subtitle halaman dipersingkat
  3. Mobile journal card: colored left-border + icon arah
  4. Secondary button "Tagihan Manual": border + glow
</objective>
