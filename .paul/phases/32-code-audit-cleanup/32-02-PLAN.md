<task type="auto">
  <name>Task 3: Lazy Loading + Bundle Splitting</name>
  <files>src/App.tsx, vite.config.ts</files>
  <action>
    **src/App.tsx — Tambah React.lazy() untuk halaman berat:**

    Ganti eager imports berikut dengan lazy imports:
    - `Finance` → `const Finance = React.lazy(() => import('./pages/Finance'))`
    - `OrderDetail` → `const OrderDetail = React.lazy(() => import('./pages/orders/OrderDetail'))`
    - `Reports` → `const Reports = React.lazy(() => import('./pages/Reports'))`
    - `AuditLogs` → `const AuditLogs = React.lazy(() => import('./pages/AuditLogs'))`
    - `OrderPriorities` → `const OrderPriorities = React.lazy(() => import('./pages/OrderPriorities'))`
    - `CancellationsReturns` → `const CancellationsReturns = React.lazy(() => import('./pages/CancellationsReturns'))`
    - `AppQueue` → `const AppQueue = React.lazy(() => import('./pages/AppQueue'))`

    Pertahankan sebagai eager imports (critical path):
    - `Login`, `Dashboard`, `ChangePassword`, `Users`, `Mitras`, `Products`, `CreateOrder`, `OrdersList`

    Tambahkan Suspense wrapper di Router JSX. Bungkus semua `<Route>` di dalam satu `<Suspense fallback={<div className="flex items-center justify-center h-screen"><div className="animate-spin rounded-full h-8 w-8 border-b-2 border-blue-600" /></div>}>`.

    **vite.config.ts — Tambah manualChunks:**

    Di dalam `build` config, tambahkan:
    ```ts
    rollupOptions: {
      output: {
        manualChunks: {
          'vendor-pdf': ['@react-pdf/renderer'],
          'vendor-charts': ['recharts'],
        }
      }
    }
    ```

    Jika `build` section belum ada di vite.config.ts, tambahkan setelah `plugins`.
  </action>

    npm run build → selesai tanpa error
